# BouMatic Digital Tools Portal

Internal web apps for BouMatic operations — hosted on GitHub Pages.

## 🔗 Live URL
`https://YOUR-USERNAME.github.io/boumatic-portal`

## 📦 Apps included

| App | File | Description |
|-----|------|-------------|
| Portal landing page | `index.html` | Links to all tools |
| Company HRMS | `hrms.html` | Skills, leave, shifts, performance, onboarding |
| Field Service Time Registration | `field-service.html` | SAC & BMR hours, OT calculation, AFAS export |

## 🚀 How to update an app

1. Edit the HTML file on your laptop
2. Open **GitHub Desktop**
3. You'll see the changed file listed
4. Add a short message (e.g. "Updated leave approval logic")
5. Click **Commit to main** → **Push origin**
6. Live URL updates within ~2 minutes
